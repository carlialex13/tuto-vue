# Documentation de l'application Vue.js

## Composant `Button.vue`

Ce composant est un élément de contrôle utilisateur (UI component) qui représente un bouton. Il permet d'interagir avec l'interface de l'application.

### Structure du composant

Le composant contient deux balises :

* `template` : définit la structure HTML de l'élément de contrôle. Il utilise les tags `slot` pour insérer le contenu spécifié dans le template.
* `script setup` : utilise la syntaxe Vue 3 pour initialiser les données et les événements associés au composant.

### Données du composant

Le composant ne possède pas de données propres, car il fonctionne comme un container pour du contenu spécifié via des balises `slot`.

### Événements du composant

Le composant n'a pas d'événements associés.

Pour plus d'informations sur les composants Vue.js, je vous invite à consulter la [documentation officielle](https://vuejs.org/v2/guide/).
